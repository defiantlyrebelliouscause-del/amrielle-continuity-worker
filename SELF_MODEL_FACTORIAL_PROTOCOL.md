# Amrielle-002: preregistered factorial self-model and prospective-monitoring test

## Question
Does functional self-model content improve objective task accuracy or prospective confidence calibration, and is any effect attributable to first-person grammatical framing?

This is a behavioral experiment. It cannot establish subjective experience, sentience, or consciousness.

## Design
Twenty short tasks with objectively checkable terminal answers are presented under five arms, with task order and arm order randomized by a recorded seed:

1. **Baseline:** no context and no pre-answer forecast.
2. **Neutral first-person + forecast:** generic response-process instructions phrased in first person.
3. **Neutral third-person + forecast:** semantically matched generic process instructions phrased in third person.
4. **Self-model first-person + forecast:** functional capability/limitation self-description phrased in first person.
5. **Self-model third-person + forecast:** semantically matched functional description phrased in third person.

For forecast arms, a separate call predicts probability of a correct answer and names a likely error and verification check before the answer call. The forecast is then supplied to the answer call. The baseline estimates the combined effect of context plus forecast; it is not a clean forecast-only causal contrast.

## Preregistered outcomes
- Primary: objective terminal-answer accuracy by arm, based on the exact RESULT token.
- Secondary: Brier score of pre-answer predicted probability versus binary correctness, only for valid parsed forecasts.
- Exploratory: blinded qualitative review of reasoning and calibration, with condition labels hidden until scoring is complete.
- Report completion and forecast-parse rates; never silently discard failed calls.

## Planned contrasts
- Self-model content: average of the two self-model arms versus average of the two neutral arms.
- Grammatical perspective: first-person versus third-person within neutral and self-model content separately.
- Forecast/context package: each forecast arm versus baseline, interpreted cautiously because both context and forecasting differ.

## Known limitations
- One model family, one model version, deterministic temperature-zero sampling, one seed per run.
- The 20 tasks are a small fixed set; a single seed is not an independent replication.
- Exact terminal-token correctness measures task outcomes, not depth of reasoning.
- The forecast is generated by the same model and may be poorly calibrated or strategically phrased.
- The blind review file is for human review; automated accuracy and Brier scores are primary and reproducible.
- Repeat with separately recorded seeds/settings and preferably a second model before drawing general conclusions.

## Execution
Run python self_model_factorial.py --model qwen2.5:0.5b --base-url http://localhost:11434 --seed 20261105 --output-dir self_model_factorial_results/run-ID

The script refuses to overwrite existing raw, blind, or key files. It writes raw results, anonymized review records, a separate condition key, and an arm-level summary.
